# Довідка по API (Нова пошта, KeyCRM)

Спільні нотатки, зібрані з офіційної документації та перевірені в проєкті `monoclo-quick-order`
(копія; оригінал: https://github.com/yvysotskis-bit/monoclo-quick-order/tree/claude/laughing-euler-gfwdjn/docs).

- `novapost/` — автентифікація, адреси, контрагенти, накладні (відділення/поштомат/адреса, контроль оплати), відстеження і коди статусів.
- `keycrm/orders.md` — створення й оновлення замовлень, поля, фільтри.

Важливо: ліміт KeyCRM — 20 запитів на хвилину **на ключ**; якщо кілька проєктів користуються одним ключем, ліміт спільний.
